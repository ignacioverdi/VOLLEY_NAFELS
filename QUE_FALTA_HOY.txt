     muestre en la pantalla. Hoy el mail anda, asi que ya no hace falta y es
     mejor que no este: si manana Resend se cae, cualquiera entraria sin mail.

     cambiarla: Resend -> API keys -> borrar "demo volley-stats" -> crear otra
     igual (Sending access + volley-stats.com) -> cambiar el valor de
     RESEND_API_KEY en Vercel -> Redeploy.

  4. EL REPOSITORIO DE GITHUB SIGUE PUBLICO
